# Contributing

Thanks for your interest in contributing to **LOVII**.

This repository is a static white paper landing (HTML/CSS/JS, no build step)
with the project README.

## What's welcome

- **Fixes** — typos, broken links, factual corrections
- **Content** — white paper updates, roadmap clarifications, screenshots
- **Improvements** — landing page polish (accessibility, performance, SEO)

## How to contribute

1. Fork the repository.
2. Create a branch: `git checkout -b fix/typo`.
3. Make your changes and commit with a clear message.
4. Open a pull request describing what changed and why.

## Code of Conduct

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md) — be respectful and kind.
