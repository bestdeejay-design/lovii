# 06 · Дизайн-канон «Лови» (lovii-design v1.9.1) — правила для нового сайта

> Репо: `lovii-design` · Хаб: bestdeejay-design.github.io/lovii-design/ ·
> Style guide: `/style-guide.html` (собирается `tools/build-style-guide.py`).
> Всё дизайнить ТОЛЬКО токенами и паттернами отсюда. Полные правила — docs/00–13.

## 1. Версия и ядро

- Текущая версия канона: **v1.9.1** (tokens/tokens.css + tokens/design-tokens.json).
- Палитра трио: pink **#f64a8a** (primary: CTA, ссылки, фокус) · tiffany **#0abab5**
  (secondary: «рядом», «в наличии», успех) · gold **#d4a854** (tertiary: премиум,
  рейтинг, лояльность) · pink-dark #c92a6a · sand #e8d5b7 · sand-soft #f6ecdf.
- Светлая тема: фон --lv-bg **#f8f5f0** (тёплый бежевый), surface #f8f8f8, ink #1a1a1a,
  gold-text #8a6a25, tiffany-text #07726f.
- Тёмная тема: фон **#171219** (слива), surface #2b2331, ink #f3ebf0,
  «пыльные» текст-пары: tiffany-text **#82c8c3**, gold-text **#d6bd8d** (контраст ≥8:1).
- Типографика: Inter (400–800) + системный стек канона (docs/03).
- Тема переключается `data-theme` + localStorage `lovii_theme`, anti-FOUC скрипт в <head>.

## 2. Правило «Тихая тёмная тема» (v1.9, docs/05 § + docs/13 §4)

Один акцент в кадре: **pink = CTA/ссылки/цифры результата**. Данные — цветом чернил.
tiffany/gold — только микрометки (фазы, бейджи). Декор почти монохром (hairline,
альфы ≤ .05–.1). Проверка «прищуром»: >3 цветовых пятен = кричит. Светлая тема остаётся
живой (полный трио-акцент).

## 3. Каркас лонгрида/сайта (docs/13)

Anti-FOUC · хедер-стекло · якорная навигация с active-nav · контейнер 860px ·
кикеры секций (01–08) · ленточные паттерны: toc · highlight · stats-трио · timeline
(фазы tiffany→pink→gold) · calc-карты с result-строкой · data-table · tag · doc-card ·
wave-декор (SMIL-морфинг, гаснет при prefers-reduced-motion) · reveal-каскад · кнопка
«наверх» · футер юр. блока (docs/11) · print-стили · SEO (JSON-LD Organization, og,
twitter, geo RU-SPE, sitemap, robots, canonical) · PWA-манифест.

## 4. Компоненты и иконки

- Реестр компонентов: docs/12 (кнопки · чипы/статусы/бейджи · поля · карточки · списки ·
  навигация · обратная связь · контентные блоки · состояния).
- Иконки: спрайт **44 символа** v1.9.1 (24px, stroke 2, round, currentColor) —
  `assets/icons.svg`; заливной **i-lo (голубь Ло)** — единственное исключение
  (fill-знак, не stroke-система). Эмоджи в UI **запрещены** (docs/09).
- Бренд-знак: **голубь Ло (по фамилии Ви)** — серый голубь с рюкзачком и сердечком на
  нём. Фавиконка/значок — `img/logos/lovii-icon.svg` (канон), favicon.svg в корнях.
- **Сердце = только «ссылка домой» на демо-странице** (вирусный элемент), нигде больше.
- Логотипы канона: lovii-logo-light.svg (#2b2b2b) / logo-dark.svg (md5 145731d8…);
  lovii-logo-dark.svg (высветленный) удалён из канона — не возвращать.

## 5. Тон бренда (docs/11)

Тёплый, честный, «свой район»: без канцелярита и штампов агрегаторов. Числа — открыто,
с дисклеймерами. Названия разделов — кикеры с нумерацией. Нейтральные подписи, капсула
480px для мобильных витрин (демо), лонгрид 860px для сайта.

## 6. Инфраструктура приёмки (обязательно перед пушем)

1. `python3 tools/check-sync.py` — сверка токенов канона иlovii-снапшота (12 файлов).
2. Пересборка style guide: `python3 tools/build-style-guide.py`.
3. Локальные скриншоты обеих тем (1280 + 390), без горизонтального скролла,
   консоль без ошибок, reveal работает.
4. Спрайт: вставка символов только через rfind("</svg>") — шапка-комментарий содержит
   примеры с `</svg>` (урок Task 37/39: преждевременное закрытие комментария).
5. Коммиты conventional; карта проектов в README (правило «один адрес → все»).

## 7. Что переносить в новый сайт из текущих артефактов

- assets/tokens.css — снапшот канона в lovii (обновлять при бампе версии).
- og-image.png — брендированная карточка 1200×630 (голубь в кикере и марке).
- manifest.json: bg #f8f5f0, theme #f64a8a (светлая) / #171219 (тёмная, через JS).
- Механика heart-CTA на демо: `<svg class="ico-heart-home">` → href="/".
