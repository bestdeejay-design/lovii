## 0. Что делать в новой сессии (кратко)

1. Прочитать этот индекс, затем `05-facts-canon.md` (факты) и `01-legacy-site.md` (база).
2. Дизайн брать только из канона: репо `lovii-design` (токены v1.9.1, docs/, style-guide).
3. Структуру и тексты — из `lovii-legacy` (6 экранов, 5 аудиторий + хаб), обновляя
   цифры до канона из `05-facts-canon.md` (в легаси цифры поколения PARAMS v1.6 —
   местами устарели, см. раздел «Расхождения»).
4. Не выдумывать цифры и формулировки. Спорное — пометить и спросить владельца.

## 3. Иерархия правды по цифрам (критично!)

1. **`lovii-invest/docs/knowledge-base/`** — CANON.md, PARAMS.md, FACT_MAP.md §12
   (решения владельца 17.07.2026). Верховный источник. Любое расхождение = ошибка.
2. **lovii.ru (white paper v2.0)** — публичное изложение канона (сверено по фактам).
3. **lovii-legacy тексты** — структура, офферы, тональность; цифры там поколения
   PARAMS v1.6 (например «PRO 4–7%») — сверять с разделом «Расхождения» в 05.
4. PDF (LOVII_General / 4Investors / 4Suppliers) и юр. DOCX — исторические, публиковать
   только после сверки с каноном.

## 4. Жёсткие стоп-правила (нарушение = переделка)

- **ЦФА упразднены** (17.07.2026): запрещены формулировки «эмитент ЦФА», «цифровые
  финансовые активы», «21% годовых», «номинал 1000 ₽». Только «доля в бизнесе / equity»
  (CANON.md §5).
- P0-стопы из ТЗ легаси: не обещать вывод баллов < 3 000 ₽; pull-механика 1% vs 0,5% —
  формулировки не менять; расчёты только через «номинальный счёт ст. 860.1».
- Прогнозы — всегда с оговоркой «не являются гарантией доходности».
- Имя банка в маркетинге не добавлять (АО «Т-Банк» — только в юридической строке).
- Эмоджи в UI запрещены (канон ДС docs/09); в старом демо они есть — не переносить.
- «Это не МЛМ»: два уровня без каскадов — принципиальная позиция (сплит 40/40/20).
