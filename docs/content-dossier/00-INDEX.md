## 4. Жёсткие стоп-правила (нарушение = переделка)

- **ЦФА упразднены** (17.07.2026): запрещены формулировки «эмитент ЦФА», «цифровые
  финансовые активы», «21% годовых», «номинал 1000 ₽». Только «доля в бизнесе / equity»
  (CANON.md §5).
- P0-стопы из ТЗ легаси: не обещать вывод баллов < 3 000 ₽; pull-механика 1% vs 0,5% —
  формулировки не менять; расчёты через «номинальный счёт ст. 860.1» — строго по
  формулировкам public-оферт (режим НС не подтверждён банком письменно — PARAMS §8,
  открытый вопрос; не «улучшать» юр. тексты).
- Цифры — только из канона lovii-docs: PRO 4–7% + 2 990 ₽ (шкалы легаси «−1 п.п.» — нет);
  доход Компании с клиента 3 292 ₽/мес (сценарии 7 258/3 920/9 924/7 460 — нет);
  банк 3,16% карты / 0,7% СБП, пул 6,84%/9,3% («~3,5/6,5» — нет).
- Прогнозы — всегда с оговоркой «не являются гарантией доходности».
- Имя банка в маркетинге не добавлять (АО «Т-Банк» — только в юридической строке).
- Эмоджи в UI запрещены (канон ДС docs/09); в старом демо они есть — не переносить.
- «Это не МЛМ»: два уровня без каскадов — принципиальная позиция (сплит 40/40/20).
