# LOVII — Локальные маркетплейсы районов города

**🌐 Версии:** [English](README.md) · [Русский](README.ru.md) · [Сайт](https://lovii.ru) · [Открытая инфо](https://axiiom-ru.github.io/lovii)

LOVII — white-label SaaS-платформа для создания и масштабирования локальных маркетплейсов микро- и малого бизнеса в отдельно взятом пространстве, фуд-корте, торговом центре, районе или городе.

- **Доставка**: 15–30 минут в пределах района
- **Локальный бизнес**: каталог товаров и услуг местных продавцов
- **Изолированная экономика района**: своя аудитория, каталог, курьерская сеть — на едином ядре
- **Статус**: MVP, мини-пилот проведён (Санкт-Петербург)

## 🗺️ Дорожная карта

1. **MVP** — фуд-корт в пилотном пространстве (10–20 поставщиков, GMV ≥ 5 млн ₽/мес)
2. **Сеть** — репликация модели на 3–5 новых районов
3. **Федерация** — кросс-локальный обмен, масштабирование по РФ и СНГ
